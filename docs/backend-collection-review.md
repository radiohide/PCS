# 后端采集梳理

2026-10-15。全部 133 个来源已分类：127 项接入原生后端，4 项待切换，2 项仅用于分组。除用户明确暂缓的 Hyper-V 四项外，其余实际来源均已原生。正式后台尚未替换；最新包为 `dist/native-five-migrated`。

## 可以直接读取的内容

| 采集内容 | 读取方式 | 日志的作用 |
|---|---|---|
| 设备、网卡、磁盘、卷、打印设备 | 系统设备与存储接口 | 补充故障、连接和操作事件 |
| 地址、路由、连接、防火墙、VPN、SMB、DNS | 网络接口及系统提供程序 | 补充连接过程和失败原因 |
| 服务、计划任务、进程、会话 | 服务、任务、进程及会话接口 | 补充每次启动、结束和执行结果 |
| 已安装软件、应用包、扩展、启动项 | 注册表、文件、WinRT、DISM | 补充安装和卸载过程 |
| 账户、组、成员和权限 | 账户与安全接口 | 补充登录、失败和受审计操作 |
| 证书、密钥元数据、防护、加密、TPM、安全启动 | 证书、安全及固件接口 | 补充保护处置与错误 |
| SIHost 等选定进程的模块 | 实际加载模块枚举、已知文件监听及复核 | 补充崩溃和加载被阻止的原因 |
| 电源、系统配置、策略 | 配置接口、注册表和文件 | 补充配置操作过程 |
| Hyper-V、WSL、Docker、Mihomo | 系统或产品接口 | 补充产品操作和错误 |

上述当前状态不以存在日志为前提。成功完整检查前后的差异进入对象与时间线；读取失败保留原状态，不能当作对象删除。

## 需要历史记录的内容

- 谁在何时登录、失败或修改了受审计设置。
- 任务每次运行、进程和服务过去的启动与结束。
- 程序崩溃、卡死、模块加载被阻止的具体原因。
- 安装、更新、防护处置的过去结果。
- 文件曾经发生的变更。

当前状态无法恢复这些过去的过程。来源可以是 Windows 日志、产品保留历史、USN 或事先运行的事件跟踪。现有 23 个事件通道、更新历史、防护历史和 USN 都已原生读取；读取 PowerShell 的事件日志也不需要运行 PowerShell。

## 本轮完成与暂缓项

| 项目 | 尚缺验证 |
|---|---|
| BitLocker、安全启动、Windows 可选组件、预配应用包、TPM | 已通过用户授权的只读增强验收并切换原生；实际编译路由在无兼容脚本目录中生成全部快照 |
| Hyper-V 虚拟机、交换机、磁盘连接、检查点 | 用户明确暂缓；四项已有原型，本机缺少实际提供程序，等待测试环境 |

没有发现必须使用 PowerShell 的采集项。剩余四项是缺少 Hyper-V 验收环境，并非只能靠脚本或日志。日志包装器现已强制原生，旧 PowerShell 配置也不会启动脚本；新包只保留 Hyper-V 兼容所需三个脚本文件。

## 实施约束与验证

采集由统一后台调度，每来源最多一个实例；通知回调只请求复查，合并重复请求并设置冷却与失败退避。采集器不自行循环，也不因自身数据和日志写入再次触发采集。已归属原生的来源失败后不自动回退脚本。

五项共读取 145 个对象：134 个可选组件、8 个预配应用及安全启动、加密卷、TPM 各一个。完整五项结果已在新隔离库进入对象和界面同用查询，积压/失败零。普通权限失败不提交空快照；增强完整读取不加载兼容脚本。参考核对的字段范围、预配应用版本验证方式和环境限制见[五项验收](refactor/acceptance/native-five-enhanced-migration.md)。旧记录回补 API 尚无管理操作入口，未运行于正式历史库。

详细接口、逐项范围及验收证据见[逐项清单](refactor/native-collection-inventory.md)和[完整方案](backend-native-collection-plan.md)。
