# 易读展示规范与实现

时间线标题使用“动作 · 对象”，结果独立显示；摘要为账户、程序及关键属性，采集项置于次行。提供程序、事件编号、写入进程等技术信息放入折叠区。正文不再自动插入泛泛提醒或截取 Windows 消息首段。

`event-presentation.js` 读取共享采集项目录中的动作名称，按事件类型选择字段、对象和结果语义。模板覆盖密钥、凭据、登录、身份权限、进程、文件、注册表、任务、服务、软件、网络、策略、WMI、安全防护、脚本和系统事件。结果解释限定来源：密钥及凭据指定事件的 ReturnCode，登录成功/失败、网络允许/阻止等。任务动作结束保留“已结束”和原始返回码，不把应用返回码统一解释成 Windows 错误码。

缺失字段使用“未记录”，隐私字段使用“已隐藏”，未关联程序显示 PID，未解析枚举保留原码。缺失、不适用、隐藏、空值和 false 不互相替代。未知事件显示来源与编号，并由 `check-event-presentation.cjs` 的历史审查模式生成 target/presentation-unmapped.json，作为待补规则清单。

详情保留易读说明/原始数据两个 Tab。默认显示执行信息与操作属性；来源说明、全量字段、数据状态及来源信息折叠。快照继续使用左右对齐的前后比较及差异高亮。系统对象显示最近成功采集、最近变化和按领域挑选的属性，全部采集属性可展开。

快照记录名称统一为初始状态、新发现、属性变化、不再发现。日志事件使用实际动作。术语提示通过可聚焦的帮助标记提供。

事件详情展开“关联记录”才执行只读查询，使用现有独立查询连接、六秒查询预算和隐私显示策略。当前支持：

- Security 事件的 ClientProcessId + ClientCreationTime 匹配 Security 4688 / Sysmon 1，时间容差 ±2 秒，且不晚于原事件。结果明确显示为时间附近的启动记录；不自动填充程序身份。
- 同任务完整路径前后五分钟的事件。
- 任务快照继续支持原有两次观察间的任务证据查询。

关联最多展示 20 条，可打开详情并返回原记录。此实现尚未建立通用账户、登录会话、任意系统对象关系图。

验证：Rust 只读关联及 PID/时间/提供程序隔离测试；九项前端检查；历史样本 94 种事件，未识别 0 种。这是该批保留样本的检查结果，不代表所有 Windows 事件均有专门模板。
