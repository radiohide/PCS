# 0010 易读名称、事件上下文与历史关联核验

| 字段 | 内容 |
| --- | --- |
| 共享入口 | 公共查询契约、固定响应集、事件参考适配器、契约检查与验收文档 |
| 整合责任人 | 基础数据线（本任务主代理整合） |
| 提出工作线 | 查询与界面线 |
| 变更类型 | 兼容增量；查询时保守纠正旧记录的不可靠关联 |
| 影响的工作线 | 基础数据、类型适配、查询界面、迁移验证 |

## 问题与新结构

原始软件登记可能没有产品名称，旧界面把它当作已安装软件。事件标题缺少所涉及的任务或账户。旧数据还可能把多个任务事件归入同一暂定对象，或仅按事件编号把其他提供程序的事件分类为任务活动。

对象摘要增加可选 `presentation`（名称、名称是否来自来源、依据、说明）；动作增加可选 `context`（事件名称、原始名称、名称依据、字段标签、程序、登录类型及对象关联核验状态）。优先使用本条原始证据，受保护或已清理的字段不可转作名称。未核实关联不输出可跳转的对象 ID，历史保存值保留在技术详情。

事件编号的回退分类必须同时检查提供程序/通道；无法确认的旧分类在读取时显示为普通系统事件。采集材料和历史记录不改写、不删除，也不在本次进行历史重新投影。

## 兼容性与版本

基础查询信封仍为版本 1，新增展示扩展单独标记 `presentation_revision: 1`。旧消费者忽略可选展示字段；新界面在旧后台省略字段时沿用已有字段并明确未知。新版固定响应集同时保留无扩展样本以验证兼容性，不因展示字段升级而拒绝可读的旧数据。

名字的搜索、排序、分页使用同一有效名称表达式。错误归属核验是读取时的保护：原始存储筛选与计数仍按保存记录工作，结果中的关联状态决定是否能把记录当作该对象的确定历史。

## 样例与检查

更新查询结构声明与可选字段固定样本。前端检查保留转义、遮罩、未知状态、原始值和对象身份完整性；旧文字断言改为默认易读和详细信息仍可追溯的双向检查。真实保留数据库以只读方式核验，并保留查询预算和大量无关历史的性能回归。实际结果见本轮验收文档。
