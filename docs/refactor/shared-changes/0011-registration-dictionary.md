# 0011 缺名软件登记的名称解释字典

| 字段 | 内容 |
| --- | --- |
| 共享入口 | 查询展示扩展、固定响应集、归属清单与验收文档 |
| 整合责任人 | 基础数据线（本任务主代理整合） |
| 提出工作线 | 查询与界面线 |
| 变更类型 | 兼容增量 |
| 影响的工作线 | 基础数据、查询界面、迁移验证 |

用户要求说明未命名软件登记是什么。新增可维护的静态 JSON 字典，由原生查询层读取编译内嵌内容；无需周期扫描、网络查询、注册表补采或 PowerShell 采集。精确限定已确认的软件登记、HKLM 卸载路径、注册表视图及已提供的发布者。真实名称优先，受保护、冲突或读取失败的字段不允许被字典绕过。

`presentation.name_status` 增加 `dictionary_matched`，附带字典标识、修订、规则、匹配依据、原始登记键和资料引用。查询基础信封版本仍为 1，展示扩展修订为 2；可选 JSON 扩展使旧消费者仍可读取原有字段。固定样本与兼容性检查同步更新。

名称、搜索、排序与分页使用同一有效名称。字典名称只解释登记标识，不代表当前已安装、仍在使用、必需、损坏或已验证发布者真实性；不会修改对象身份、原始证据及安装状态。未覆盖项保持未识别，同名字典结果不合并不同对象。

条目需记录一手资料或本机安装材料依据。资料仅支持组件用途而不能确认登记映射时，不得编造确定名称。字典版本随内容更新，查询游标应避免跨字典版本复用。

本次数据无迁移，历史保留。验收覆盖匹配边界、真实名称优先、保护值、SQL 引用安全、排序分页、原始证据保留、浏览器可见内容和实际后台响应；结果随本轮验收报告记录。
