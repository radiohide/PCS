## 问题与行为变化

默认系统对象列表虽然只返回 50 行，摘要仍需精确统计当前查询范围的证据地址。在隔离副本的 1,581,291 条观察引用中，重复引用使原 `COUNT(DISTINCT evidence_id)` 成为主要开销。状态与设置读取还会等待采集、投影共用的写锁，使界面和后台启动判断一起变慢。

对象类别补齐“用户与账户”“文件与文件夹”“运行程序与会话”，并将部分明显偏技术的类型改成简短用途名称。请求里的类别、类型及对象身份保持原值。对象列表超时提示使用本页确实存在的类别、类型和名称筛选；原始错误保留在折叠详情。默认列表可以直接重试，筛选是可选操作。本轮没有扩大查询超时、删减历史或用估算替代精确计数。

## 精确计数与可选索引

写入入口以幂等方式新增部分覆盖索引 `evidence_refs_observation_address`，键为 `(evidence_id, subject_id)`，仅覆盖 `subject_kind='observation'`。最终计数先将当前筛选和游标窗口对应的 `matched` 对象集合 `MATERIALIZED` 一次，四类精确计数共同使用该集合，避免重复计算有效名称和历史时间条件。物化内容仅含对象 ID 及其规范文本形式，不复制长证据地址。

存在新索引时，证据计数按实际引用规模选择路径：空选择直接返回 0；匹配对象占全表至少 90% 时直接逐地址跳跃；其余选择先通过原有对象索引做有上限的引用探测。探测上限取全表引用数约四分之一，最低 1 万、最高 25 万；未达到上限时按匹配对象执行原有 `COUNT(DISTINCT)`，达到上限时使用逐地址跳跃。全表对象数与引用数通过无 `WHERE` 的 `count(*)` 获取，可使用 SQLite 的 `Count` 操作。引用探测仅选择执行路径，两条最终路径都返回精确计数。

逐地址路径通过递归 `MIN` 和严格下界跳到下一个不同地址，再检查是否存在匹配对象的引用。最终方案不再按“512 个对象”选路，少量对象也可能包含大量重复引用。没有新索引的旧只读库始终保留原有按对象 `COUNT(DISTINCT)` 路径，不执行新索引探测或创建索引。

计数含义保持兼容：按地址字符串精确去重，仍按原对象身份的文本匹配规则判断引用；不会因为新查询额外连接材料表而遗漏已清理或材料缺失、但仍被匹配对象引用的地址。对象、动作、来源绑定和证据各自统计，不相加；筛选、游标窗口和分页水位线仍共同约束结果。

同时修复“最近变化优先”（`ChangedDesc`）对不存在的 `changed_at` SQL 别名的引用。列表排序、游标条件和计数使用同一事实历史最近变化时间表达式，详情也复用该表达式。没有变化记录的对象仍返回 `changed_at: null`，只在排序和游标键中统一使用空字符串；相同时间继续按对象 ID 升序稳定排列，不虚构变化时间。

数据库 `user_version` 保持 **9**，查询信封与展示扩展版本不变。新索引是可选加速结构，未修改表、历史、用户设置或投影规则。只读连接不创建索引、不迁移数据库；旧 schema 9 程序仍可读取同一表，普通 SQLite 写入会维护已有索引。首次创建由单条原子 `CREATE INDEX` 完成，中断时不留下半成品索引；后续写入入口可重试。更高数据库版本的拒绝规则保持不变。

## 轻量读取、隐私与锁顺序

`Status`、监控设置、隐私设置、采集项控制和文件/文件夹/运行监控设置改由独立只读连接处理，SQL 预算为 2 秒，不获取共享写 `Store`。普通对象查询继续使用原有 6 秒读取预算。插件列表先取得内存快照，再从独立连接读取当前隐私设置。

内存状态只在短锁中复制或发布，数据库等待放在锁外；USN 失败先持久化，再发布状态。插件配置先取得写 `Store`，再短暂持有调度锁，避免插件读取继承等待写锁的时间。能力检查结果先发布，其待保存历史另由计数器跟踪；退出仍等待保存完成。检查任务先登记正在执行，再复查停止标志，避免退出等待通过后又启动检查。

所有返回的数据继续按当前隐私设置处理。隐私设置读取失败返回错误，不使用旧缓存推断显示权限；遮罩处理的是返回副本，内存中的受保护材料不被改写。`Shutdown` 只返回常量退出确认，不含来源数据，因此不需要等待数据库或隐私读取。

## 退出、替换与桌面启动

替换保留原 Windows 账户 SID 校验，并始终使用所选账户和已解析数据目录对应的管道。替换请求直接发送 `Shutdown`，不先依赖可能阻塞的状态读取；确认退出或回复丢失时，只允许等待旧管道释放。新进程必须先取得 `FIRST_PIPE_INSTANCE`，然后才能打开数据库、启动采集。权限拒绝、显式后台拒绝和非 EOF 协议错误不会被当成旧实例不存在。

桌面启动探测只在 `NotFound` 时允许启动新的后台进程。已有端点超时、断连、权限拒绝或未知错误会返回错误，不触发另一个后台。此判断与管道独占共同保留同账户、同目录的实例边界；本轮没有提权桌面或改变 UAC 授权流程。
