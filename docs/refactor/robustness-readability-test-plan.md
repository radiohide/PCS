# PCScope 采集鲁棒性与可读性测试方案

日期：2026-10-19。方案版本：第二版，对应[实施方案](robustness-readability-implementation-plan.md)。代码基线为 0.2.13，数据库结构 10；以下为待执行验收。

测试目标是证明异常不会污染对象状态、材料可以恢复、历史过程完整、显示易懂且性能可持续。每个用例按涉及范围验证原始材料、身份和字段、历史行动、查询、界面；不能只比较最终一句文案。

## 产品标准验收

| 产品标准 | 必须验证的行为 | 对应用例 |
| --- | --- | --- |
| 有效结果直接给结论，时间放旁边 | 正常显示运行中／未加载／已停用；明确操作显示实际结果；不增加泛化免责声明 | U01、U11、U13 |
| 短暂延迟不打扰用户 | 单次失败和普通处理等待不加卡片警告；持续影响当前判断才提示对应范围 | U02、U04、U05 |
| 失败说明范围和恢复办法 | 同一来源集中提示一次；重新检查／申请权限／重连执行真实动作，完成后提示消退 | U16、D01、D04 |
| 不在每张卡片反复辩解 | 默认卡片无通用“不代表／不能确认”段落；原始依据和技术限制放详情 | U12、U13、U16 |
| 用户一眼看懂发生了什么 | 独立阅读默认卡片，正确识别对象、变化、时间含义和处理需求 | 人工可读性验收及 U06、U07、U11 |

不能只用禁词扫描判合格：确有未知字段或权限失败时仍要明确表达；重点核对默认页面能否给出有依据的结论，是否把内部处理细节变成用户负担。

## 环境与执行边界

| 环境 | 执行内容 | 边界 |
| --- | --- | --- |
| 普通账户 | 编译、离线回放、临时库故障注入、普通只读原生采集、真实页面交互 | 不连接正式库做写入或故障实验 |
| 低完整性进程 | 验证系统接口拒读、范围缩减和 IPC 拒绝行为 | 与普通权限结果分开，不能放松权限检查使测试通过 |
| 同账户管理员 | 冻结二进制后做增强只读接口验收 | 实施时需要新的明确 UAC 授权；旧对话的一次性授权不重复使用 |
| 可恢复虚拟机 | 任务、服务、软件、驱动的真实安装移除和失败回滚；系统日志配置组合 | 先建立恢复点或虚拟机快照，不在日常系统制造这些故障 |
| Sysmon 环境 | 原生输出的实际事件版本及完整链路 | 无组件时离线回放与实机结果分列，不自行安装或开启审计 |
| Hyper-V 环境 | 四项兼容来源及后续原生迁移 | 当前缺环境；契约和无环境行为可测试，实机仍为环境受限 |

故障注入通过测试存储层、隔离工作进程和受限临时空间实现，不能填满系统盘、终止正式后台或损坏正式数据库。断电场景在可恢复虚拟机或模拟存储故障中验证；普通杀进程不能声称覆盖真实断电持久性。

## 完整接收和发布测试

| ID | 输入或操作 | 通过断言 |
| --- | --- | --- |
| I01 | 在收到第 1、8、15 个分块后终止隔离接收进程 | 重启仍读取上轮完整状态；本轮不产生出现、缺席或部分字段 |
| I02 | 全部分块保存但未收到结束标记；重启后补发结束标记 | 未结束时不发布；完成清单校验后只发布一次 |
| I03 | 发布事务提交前、提交后但回复前终止进程，再重发 | 只出现完整旧轮或完整新轮；材料、动作、发布指针无重复，回复丢失不导致漏接 |
| I04 | 缺片、重复同内容、重复异内容、跨片重复对象 ID、错误摘要 | 同内容幂等；其他冲突拒绝整轮，不改变当前基线，错误原因可区分 |
| I05 | 分片接收、模型准备和展示准备过程中循环查询；A 基于 B1 准备时 B2 先发布 | 每个响应固定完整发布代次；不出现新状态配旧事实或半轮批量缺席；A2 发布不覆盖 B2 的字段，摘要和计数一致；进度只反映真实完成 |
| I06 | 大快照、超长单项、受保护字段；重复发送缓存的原始块 | 原文重组与存储摘要一致；内存和磁盘受限；加密随机性不产生假变化或误判重发冲突 |
| I07 | 在保存分块、提交、派生和发布各阶段注入 busy／full／写入错误 | 不提前确认成功；不推进未保存材料的断点；旧状态可读；恢复后可续跑 |
| I08 | 活跃和超期未完成批次混合，执行回收并重启 | 仅回收符合规则且未引用的超期材料；当前批次、已发布证据和恢复所需材料仍可读取 |
| I09 | N 超时后 N+1 完成，N 始终不返回或随后迟到；系统时间回拨；同时间不同轮次 | N+1 不永久等待失效 N，基于最近有效轮次比较；N 迟到仅保留历史；下一轮差分正确，无负区间或时间倒退导致的状态回滚；不将跳过规则用于未保存的日志 |
| I10 | 新后台代次启动，旧采集进程继续发送；恢复旧备份后旧进程重连 | 旧执行代次不能推进状态；新序号持久递增；同已接收轮次重放幂等 |
| I11 | 畸形 JSON、超长行、错误协议、非法时间、错误字段类型混入材料 | 按完整性单位拒绝或隔离；不能静默转成空清单；不崩溃、不把 false／0 当缺失 |
| I12 | 一个来源／CNG 范围失败，其他来源正常 | 仅失败范围停止更新并退避；健康范围继续；没有高频反复启动 |
| I13 | 采集中切换开关、监控名单、普通／增强权限和用户范围 | 旧配置结果不能发布到新范围；缩小范围不生成删除；新范围按独立基线处理 |
| I14 | 旧 v1 单消息、已登记 16 分片、新分块协议和未知布局混合；升级已有旧分片库 | 已知完整布局正确包装；未知布局不猜测；旧绑定接管后无重复对象和批量首次出现；下一轮真实移除可产生缺席；旧证据地址仍可查；不兼容能力明确拒绝 |

## 生命周期和身份测试

| ID | 输入或操作 | 通过断言 |
| --- | --- | --- |
| L01 | 首轮含 A，第二轮为空 | 首轮只建基线；第二轮一条类型正确的缺席历史；当前状态一致 |
| L02 | 基线空 → A → 空 → A → 空，并重复回放 | 四次转换各一条，第二次出现为再现；对象代际符合类型规则；回放不增加动作 |
| L03 | 父项 ID 不变，子集合 `[A,B] → [B,C] → []`；另测缺失／拒读数组 | A/C/B 各自增减；父对象不反复新增；缺失或不可读不清空旧子集合 |
| L04 | 设备 ID 不变，驱动 A → B → A；另测两个版本并存 | 设备仍为同一对象；两次旧绑定退出和新绑定加入；并存不错误归为替换 |
| L05 | A/B 两来源支持同一对象；A 缺席、失败、禁用；再测 B 过期 | 新鲜有效 B 存在时对象不消失；来源和对象状态分开；B 过期后不继续宣称当前有效 |
| L06 | 相同 CLSID 多角色；用户／机器、32／64 位同名登记 | 一角色移除不使整体消失；作用范围按真实身份处理，历史不串联 |
| L07 | PID 复用、任务删除重建、同路径文件替换 | PID＋创建时间、文件身份和类型代际正确区分；旧实例历史不写到新实例 |
| L08 | TCP 连接、监听、UDP 暂定身份加入后消失；短进程和打印任务 | 加入与缺席身份条件对称；不充分身份保留来源记录；快照未见的活动不补造 |
| L09 | 同字段 A → B → A；中间穿插未知、读取失败、保护值 | 真变化完整；未知不变成关闭；保护策略不被旧值绕过，字段规范化不掩盖有效变化 |
| L10 | 文件改名、同路径换文件、拒读、移出名单和卷变化 | 五类结果区分；停止监控不写删除；USN 与文件状态按真实身份关联 |
| L11 | 同一操作多来源日志、同名不同操作、同秒不同对象 | 只按可靠身份和操作 ID 合并证据；30 秒分组不去重动作，不合并对象 |
| L12 | 测试宿主加载 DLL → 文件变化 → 文件拒读／恢复 → 卸载／进程退出 | 模块加载与磁盘文件状态分开；文件变化不直接推断 sihost 启动失败；地址变化仍保留 |

## 事件解析和操作结果测试

| ID | 输入或操作 | 通过断言 |
| --- | --- | --- |
| E01 | 原生实际输出的 Sysmon 1/5、6/7、3、11/23/26 | 从通用 kind 进入后端解码、动作和查询；身份充分时关联正确；文件名单外不扩展采集 |
| E02 | 相同事件编号但不同 provider／channel／version；新增字段版本 | 不误用其他事件规则；未知版本保留材料并标明解析能力；支持的扩展字段不导致整体丢弃 |
| E03 | 缺 PID 创建时间、ProcessGuid、操作 ID、有效源时间等情况 | 不凭 PID／名称硬关联；精度如实保留；无法形成当前状态时仍可读历史动作 |
| E04 | 服务启停事件与快照先后交错，插入迟到旧事件和跨通道冲突 | 可靠新事件可直接更新状态；旧事件不回滚；快照可校正；无可比顺序不按到达顺序决胜 |
| E05 | 同批重放、旧序号、同 XML 两次独立 DPAPI 加密、相同事件 ID 真实原文改变、提交后回复丢失 | 相同原文不同密文不重复且不冲突；真实原文改变拒绝；检查点与原始材料同事务；没有提前 ACK，原始 ACK 不冒充展示完成 |
| E06 | 一条超过当前信封预算的事件，前后各有正常事件 | 正文完整保存并验证后，事件一条、断点推进一次；其余已保存材料继续解析 |
| E07 | 大正文缺块、摘要损坏、空间不足、正文成功但事件事务失败 | 不产生悬空引用，不越过未保存原文推进断点；恢复重发无重复 |
| E08 | 正常、缺解析器、永久格式错误、暂时性错误混合 | 正常解析继续；坏材料隔离；暂时错误退避；缺规则等待适用版本，无无限热重试 |
| E09 | 日志清空、轮转、检查点锚点改变、源时间缺失 | 新 epoch 与保留材料分开；旧记录不重贴到新对象；缺时间不冒充精确发生时间 |
| E10 | 任务／MSI／更新／驱动操作的开始、结束、失败、取消、回滚、重启要求及缺终点 | 阶段和结果分别正确；SetupAPI 半区段不提前完成；“结束”不等于成功；无终点不补成功 |

| M08 | 原始证据已清理、保护材料不可读、旧规则缺时间或身份 | 对应材料列为不能重算或受限；不造字段；新采集和无关历史继续工作 |

## 显示和交互测试

| ID | 输入或操作 | 通过断言 |
| --- | --- | --- |
| U01 | 成功检查处于正常周期；已打开列表和详情，无新材料且 revision 不变，假时钟跨过时效边界 | 边界内显示当前状态；DOM 自动改为上次状态，不能靠测试主动重新查询才生效；事实与历史动作不变；计时器和请求有界，不会每秒重建展示表 |

| U06 | 不同进程加载同名模块、同程序多实例 | 默认区分所属进程，必要时区分启动时间；未加载仅作用于对应实例；跳转正确 |
| U07 | 同名不同路径文件、同名任务、不同域账户、同名软件登记 | 使用最短必要上下文；不改内部身份、不合并历史；长名和 Unicode 正常排版 |
| U08 | 14 项枚举已知值、数字／字符串、大小写、未知新增值和错误字段类型 | 支持值逐项正确；不同接口同数字不串字典；未知保留详情且不判健康，不崩溃 |
| U09 | SMB Dialect、容器描述、安全产品状态代码 | 版本和描述正常显示；没有可靠解释的产品代码不显示“正常／关闭”；不以填满字典为目标 |
| U10 | 未提供、拒读、冲突、受保护值、false、0、空数组和字典匹配 | 值状态不混淆；有效零值保留；别名、组合名称和历史值不泄露保护内容 |
| U11 | 模块先加载后离开再出现；对象名称后来修改 | 时间线保持当时动作和名称；详情为最新已发布状态；旧历史不跟着当前状态改写 |
| U12 | 普通按需服务停止；另测有明确故障和依赖证据的停止 | 普通停止没有泛化功能故障文案；有依据时只显示对应影响；历史影响不冒充当前影响 |
| U13 | 同一行动在时间线、对象历史、比较和详情中展示；规则升级；明确操作结果与普通记录对照 | 含义与单位一致；前后值明确；充分证据直接显示退出／删除／安装成功或失败；不降格成笼统有记录；响应使用一致规则版本；技术材料默认折叠 |
| U14 | 区间起止各差 29／30／31 秒；同秒事件；分类混合、折叠和全部展开 | 30 秒规则边界正确；仅改变排版；分类数量和内容对应，折叠模式保留 |
| U15 | 前 200 条、预加载、翻页、筛选、刷新期间新代发布；请求取消 | 无重复漏页或跨代拼接；游标失效时明确刷新；滚动和筛选保持；无重叠请求风暴 |
| U16 | 例行读数、签名更新摘要、模块加载地址变化、全局采集异常和不可恢复的旧历史缺口；点击恢复操作 | 例行入口仍可查看完整记录；地址变化保留；同一失败集中提示一次，不铺满卡片；按钮发出正确请求且不重复启动；未排队不写自动重试，成功后提示消退；旧历史缺口不生成长期全局警告 |

U01–U13 的通用状态和字段规则必须参数化覆盖全部 101 类型；没有自然运行状态的类型使用配置或存在状态，不能为了套测试造“运行中”。UI 浏览器测试重点验证实际 DOM、路由、按钮、展开和查询请求，字符串检查只是补充。

增加人工可读性验收：使用不少于 20 张覆盖正常、故障、配置、快照和明确操作结果的卡片，由至少两名非实现者独立阅读。每张先展示默认状态 5 秒，再回答“哪个对象、发生什么、说的是当时还是现在、是否需要处理”；适用问题答对率目标不低于 90%，历史／当前或进程／文件的严重混淆为零。随后允许展开，检查能否找到当前状态、依据和恢复入口。普通卡片默认不超过两行业务说明，长名称自然换行和时间标签另计；不靠隐藏关键上下文满足行数。暂无独立参与者时记录未执行，不能用模型自评代替通过。

| P05 | 同路径每秒 100 次通知持续 60 秒、设备通知突发、内部文件反复写入 | 同来源有效任务 ≤ 1；重复通知最多一个执行和一个待复查；输入结束后在稳定等待＋一次复查预算内收敛；DB/WAL/SHM 和内部产物不触发自循环 |

| P07 | 预热后 2 小时稳定运行，另安排有限的 8 小时综合运行 | 无变化不新增对象／行动；进程与待办不持续增长；同负载下后段内存中位数较预热基线增长 ≤ 10%；原始历史正常增长单列，不误当泄漏 |
| P08 | 127 个原生来源执行、4 个兼容来源单列；取消耗时查询 | 原生执行期间启动 PowerShell／pwsh 次数为 0；单来源并发 ≤ 1、全局受现有调度限额约束；查询取消 ≤ 1 s；取消不影响采集和已保存历史 |

P02 的峰值取 S0 固定配置的实测输入，并同时记录每秒字节数和记录数。不能用大量空记录制造漂亮吞吐。查询组合包含常用筛选、名称排序、最近变化、历史详情及含例行更新；复杂筛选不在测试中悄悄排除。
