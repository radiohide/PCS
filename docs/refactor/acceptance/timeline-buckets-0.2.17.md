# 0.2.17 固定时间分组验收

日期：2026-10-20。桌面界面 0.2.17，后台继续使用已启用的 0.2.16 优化版。

## 产品规则

- 时间线默认按 5 分钟分组，可选择 1、5、10、15、30、60 分钟。选择保存在当前界面的本地设置中，刷新、重新打开和清空筛选均保留；无效值回退到 5 分钟。
- 分组对齐本地时钟，例如 11:00–11:05、11:05–11:10。起点包含、终点不包含。不同类型的记录共用时间组，空组不显示。
- 有确切发生时间的记录按发生时间归组；有效变化区间按区间结束时间归组；缺失或无效时间使用记录时间；所有时间都缺失时显示“时间未记录”。
- 左侧标题统一为“时间段”。卡片独立显示实际发生时间、“变化区间”或“记录于”，原始时间和历史数据不改写。一条记录只出现一次。
- 跨页追加使用固定组键，边界和已有卡片不移动。保留分类开关、分类数量、单组及全部折叠状态、已打开详情和左侧固定时间栏。页尾未完成的时间组显示“已加载 N 条”。
- 切换分组粒度取消旧批次的渲染并重新加载当前筛选的首屏。每页仍为 200 条、分 50 条绘制；不为填满时间组读取全部历史。
- 夏令时重复时段使用绝对时间区分，并在相同本地时段旁显示 UTC 偏移，避免两个 01:15 被误认为同一组。

## 实现与性能

分组成员通过 Map 按时间组键定位，分组阶段按记录数线性处理，再排序时间组。追加页面通过组键定位已有 DOM；分类计数只增量计算新增卡片。日期格式化直接读取本地日期字段，避免每条记录重复创建本地化格式器。

数据库、查询契约、展示准备数据、采集周期均无变化。界面版本独立升至 0.2.17，不需要替换增强后台或重新处理历史。
