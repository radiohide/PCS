# 已采设备名称恢复

2026-10-13，模型 1.2.4，预览包 `dist/device-names`。

用户提供的 Battery 类别包含两条实际设备：`ACPI\ACPI0003\0` 的来源名称是 `Microsoft AC Adapter`，`ACPI\PNP0C0A\0` 是 `Microsoft ACPI-Compliant Control Method Battery`。采集已经取得名称，但硬件适配器与模型目录遗漏了 name 字段，因此全部显示泛名；这是转换缺陷，不是管理员权限不足。

已补齐可变设备名称字段，身份继续使用设备 ID。精确设备 ID、原名称、已确认身份同时匹配时，显示“电源适配器”或“电池”，Battery 类别显示“电池与电源”；自定义名称、其他设备、暂定身份和受保护名称不套用此别名。未匹配的类别保留来源文字。

实库 212 条当前设备中，原始材料有 206 个非空名称；修复前名称事实为 0，正常采集处理后为 206。其余 6 条来源没有名称，仍保持未知。本轮没有猜测设备型号、批量改写历史、变更设备身份或增加采集循环。

验证：273 项契约测试通过；设备适配用例确认名称和原设备 ID 同时保留。展示、身份/隐私别名边界、目录生成及查询契约检查通过。最终后台 1380、桌面 20508，增强权限保持；6 次实际请求核对两设备的名称搜索与详情通过，真实返回值经产品列表渲染器分别显示“电源适配器”“电池”。29 文件复制哈希核验通过；原有 MinGW manifest 警告仍保留。
