# 原生快照缺席到对象和时间线

2026-10-14。隔离回放发现真实链路缺口：完整快照已经在原始记录保存 `object.no_longer_observed`，但没有生成持久对象处理任务，系统对象仍 active，界面同用时间线查询没有对应行动。

修复在缺席差异入库事务内写入 record 证据和对象处理队列。先处理这一轮仍存在的记录，再处理缺席，避免一个登记角色消失时误判整个对象。仅匹配原来源绑定、机器/安装/业务范围及完整原生身份下唯一的已有对象；不创建缺席对象，不覆盖较新的存在，不把读取失败、不完整材料或关闭项当作缺席。

对象更新为 not_observed，保留原 last_observed_at，设置 last_absent_at；时间线生成“本次检查未找到此对象”，时间为最后存在至此次完整读取的区间，不填精确发生时间、操作者或程序。历史字段值不会当作新字段观察。其他仍保留的同源登记角色保护对象，查找使用当前对象 source/id 索引及有界候选，不扫描整个证据历史；超出候选预算保持旧状态。资源样本、日志能力等非对象读取不会生成缺席对象处理任务。
