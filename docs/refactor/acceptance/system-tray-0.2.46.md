# 0.2.46 系统托盘常驻

Windows 通知区域增加 PCScope 图标。左键打开主窗口；右键菜单包含“打开 PCScope”、后台连接状态、“退出界面（后台继续采集）”。关闭主窗口收起到托盘；再次双击可执行文件唤回原窗口。退出界面不发送后台停止命令。

托盘使用 Tauri 原生托盘接口及原有程序图标。状态复用现有每 10 秒的连接恢复循环，不增加采集或独立状态轮询；连续三次失败才更新断连提示。图标建立失败会阻止正常启动，不把没有恢复入口的窗口隐藏。

单实例按现有后台端点的账户和规范化数据目录身份区分，使用 Windows 自动复位事件：重复启动在创建窗口前发出唤回信号并退出。不同数据目录可独立打开；程序版本、debug/正常入口不会导致相同数据目录多开。事件信号在首次窗口尚未建立时仍保留，进程退出后系统释放句柄。

## 验证

- 桌面 Rust 13 项测试通过，包含重复启动信号、不同实例隔离及句柄释放后重新启动。
- 设置页面加载、并发请求去重和失败重试浏览器回归通过。
- Windows 实机显示 0.2.46；再次运行正常入口，第二个进程正常退出，只留下一个桌面进程。
- 隔离目录中禁用所有采集任务，通过实际 Alt+F4 关闭窗口；窗口从列表消失，桌面和后台仍在。重新运行相同参数后恢复同一窗口和进程。
- 原生菜单和左键回调已编译验证；未完成鼠标逐项点击的实机验收。
- 桌面 debug 构建、依赖准备完成；固定正常入口仍为 dist/dev。本次仅更新桌面，兼容现有 0.2.45 后台，不替换后台二进制或修改历史与采集配置。

API 依据：[Tauri 系统托盘](https://v2.tauri.app/learn/system-tray/)及仓库使用的 Tauri 2.11.5 源码。窗口目录参数继续沿用现有启动配置优先级。
