## 读取范围

`ApplicationFiles.cs` 在编译宿主中直接读取文件和 JSON、版本、ACL、摘要、备用数据流和原生文件身份，不启动软件、扩展或 npm，不读取 SSH 私钥，SSH 公钥内容与注释不入库。

浏览器保留原 Default/Profile 目录和 Preferences/Secure Preferences 次序、记录状态、禁用原因及路径，读取失败仍单独记录 preferences_status。安装清单不改为“已运行”。编辑器和 npm 保留标准目录、作用域包目录及原目录身份。JSON 维持既有大小、系统默认编码/BOM、大小写属性读取及空数组表示；大小写歧义键拒绝提交。读取期间文件变更不提交不稳定结果。

保留原目录链接策略：编辑器允许原有目录/清单链接；npm 和浏览器仍拒绝原限定层级的重解析点。Chrome 先筛选指定 Profile 再检查，未将其他目录的链接错误扩大为来源失败。

便携程序仅在已配置本地目录递归，计数包含所有访问条目，仅记录 exe/dll/msi。保留选定目录、摘要设置、数量和大小预算组成的范围摘要；读取版本、公司、权限、流、摘要和卷/文件身份，签名状态维持未验证。普通文件/目录及程序记录不冒充安装时间；不跟随目录重解析点，不保存内容。
