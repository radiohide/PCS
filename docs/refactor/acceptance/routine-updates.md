# 日常更新与实际变化（0.2.6）

用户要求保留模块加载地址变化，其余按可读性审查整改。模块的采集、默认显示和详情显示均保留。

| 项目 | 默认主时间线 | 完整记录 |
|---|---|---|
| 用户资料最近使用 | 时间刷新不当作配置变化展示 | 最近使用时间已更新，显示新时间 |
| 计划任务最近/下次执行 | 不逐次显示时间字段刷新；实际开始、结束、失败日志与结果变化保留 | 当前时间在主要信息；运行时间、结果与日志在执行记录中，配置变化单列 |
| 系统时间内部计数 | 仅已知运行计数更新不进入主时间线 | 配置键变化和未知键保留 |
| 网卡连接速率 | 常规读数不进入主时间线；连接状态变化保留 | 当前连接速率 |
| 电量 | 跨越 20% / 10% 边界及恢复时显示；同一区间不逐个百分点刷屏 | 所有读数变化可查；未知或异常读数不隐藏 |
| 病毒库/防护程序版本 | 简短摘要；同对象、同次观察两项更新合为一条 | 原版本、各字段记录保留；摘要受分页游标水位限制 |
| 登录初始化受保护数据 | 相同实际值不生成假变化；已有纯密文变化不显示为修改 | 原始材料保留；实际值变化继续显示，不降低脱敏要求 |

默认“主要变化”，可切换“含日常更新”。SQL 在分页前筛选，避免整页被过滤后无法继续加载。对象历史包含日常更新；仅确认为相同值的假变化不再作为修改展示。

时间同步内部键白名单为 SecureTimeEstimated、SecureTimeHigh、SecureTimeLow、SecureTimeTickCount、SecureTimeConfidence、LastKnownGoodTime、SpecialPollTimeRemaining、LastGoodSampleInfo。Type、NtpServer 等配置、未知字段、配置与计数混合变化均保留。

任务记录不把当前结果套到过去执行上；只按记录自身结果说明成功或失败。详情提供最近记录，更多历史仍可自动加载。没有新增采集、PowerShell 循环或系统审计修改。

受保护数据在原账户本地比较实际值，不向界面传回明文或额外摘要。解密失败保留差异，避免错误隐藏。旧字段变化的 target_type 可能是来源标识，查询优先使用关联对象类型；回归包含这种真实形态。

验证：273 项契约、27 项后台、171 项存储完整回归通过；旧来源标识修正后另跑 7 项专门回归。页面 29 个实际交互场景及自动加载检查通过，覆盖分页前过滤、旧数据保留、保护值重复采集与实际修改、未知配置、电量阈值、模块显示、防护摘要及游标一致性。

实际历史只读快照：保留行动 13,916 条，有效字段变化 565 条，其中日常更新 371 条、默认主要变化 194 条；这是字段变化子集的筛选，不是全部行动的删减。模块地址变化两条在两种视图中均保留，完整复核耗时 2.64 秒，数据库无写入。

2026-10-15 已经用户确认单次 UAC，同一账户将增强后台由 PID 40264 切换至 55204；数据目录、实例标识、增强权限与设置不变。实际 IPC 核对 60 条资料使用时间在主时间线隐藏、完整记录可见，两条模块地址变化保持可见。正常与 debug 包均在原固定目录，启动配置校验未变化。

采集全过程其他缺口保留：重现、子集合差分、驱动绑定替换、Sysmon 生产事件分类、投影积压及历史回补仍按原队列处理。
