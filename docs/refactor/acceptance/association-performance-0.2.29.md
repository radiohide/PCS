0.2.29 使用来源、条目、范围和原始记录地址，直接命中既有唯一索引；完整身份查询也先按对象完整身份定位，再查精确绑定。没有新建大索引，没有迁移或复制原始数据。相同关联决定不再重复触发展示准备。缺字段的次要证据仍保存独立重放凭据，避免后续回放增加重复动作。
