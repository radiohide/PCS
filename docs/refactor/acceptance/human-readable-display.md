# 对象名称与时间线易读性验收

日期：2026-10-12。基准：根目录 `pcscope`。用户要求默认显示人能理解的名称、当前状态与影响，详细技术名称默认收起。

## 已实现行为

- 对象优先使用实际名称；完整路径、内部标识、来源代码和原始字段在详情保留。没有名称的软件登记集中折叠，说明不能仅凭登记判断软件已安装，不再显示“已安装软件（名称未提供）·记录 1”。
- 时间线使用本条事件中的任务、账户和程序名称。开始、结束与成功分开；后台服务使用账户不解释为有人登录桌面；模块加载地址变化不解释为文件损坏。
- 默认显示易读状态和值，未知状态保持未知，布尔值使用“开启/关闭”等文字。更新错误码、原始动作名、完整前后值默认折叠。
- 对旧事件的对象关联进行只读核验，未核实或不一致时不提供错误跳转。对象详情把这类历史记录单独折叠，原记录和旧关联保留。
- 事件编号回退分类检查提供程序和通道。无法复核的旧分类按普通系统事件显示，不把其他应用的同号事件当作任务运行。
- 插件、权限状态及旧记录详情沿用同一可读性原则。原始数据页仍保留完整材料。

## 数据来源与边界

保留数据库的只读软件样本共 39 条：21 条有产品名称、18 条原始登记没有可用名称。首条 AddressBook 登记的原始 `values={}`，这不是适配器漏掉名称；程序不虚构产品名称或安装状态。样本对应指定查询和取样时间，不代表机器全部软件数量。

时间线通过本条动作的证据提取名称，受保护和已清理的字段不用于构造显示名。不同任务曾被旧后台归入同一个暂定对象；本轮读取时纠正不可靠的展示与导航，不对历史库批量重投影。来源分类、筛选及计数中的历史保存值可能仍反映旧关联，默认展示明确区分核实状态。

兼容扩展登记：[0010](../shared-changes/0010-readable-presentation.md)。原有查询信封版本保持兼容，展示扩展版本为 1。查询保持 6 秒预算；从每条动作的证据引用定位原始记录，避免反复扫描整个事件库。
