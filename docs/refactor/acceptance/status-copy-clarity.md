# 状态提示表述整改

2026-10-15。覆盖全部 101 种系统对象，以及时间线、对象列表、树形、对象详情、状态对比、模块文件监控和采集权限检查。

## 表述规则

提示直接说明对象、发生了什么、缺少哪项资料。只有已知影响才说明影响；不重复添加“是否影响使用尚未确认”等泛化句子。

完整清单中未再出现、来源明确报告结束、来源明确报告删除分别表达。读取失败单独显示，不改变此前保存的对象状态。

## 跨页面一致性

- 未再列出的对象优先显示本次清单结果，避免继续把旧的“运行中”等属性当作最近状态。
- 对象详情把这些旧属性放在“上次采集的信息”下，并显示采集时间。
- 树形节点、对象列表、详情标题和状态对比的对象选择框共用同一个状态解释。
- 状态对比中明确标出未再列出、已结束或已移除，下面继续保留历史变化。
- 时间线继续区分发生时间、区间内变化和记录时间；详情中的区间说明统一为“发生在此期间”。
- 安装登记的字典名称注明“名称根据安装登记识别”，不再重复加入是否仍在使用的泛化判断。
