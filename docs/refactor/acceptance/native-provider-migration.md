# 原生系统提供程序迁移验收

日期：2026-10-14。本批新增 14 项原生路由，累计迁移 55 项。当前源码为 95 原生 / 36 兼容 / 2 分组；原全量目标及部署、权限和环境门槛继续开放。

## 接入内容与边界

存储 3 项为磁盘、分区和物理磁盘状态；安全 5 项为 Defender 状态、Defender 配置、安全产品登记、Defender 保留的检测历史和 Device Guard；网络 3 项为网络配置文件、SMB 映射和本机 SMB 服务端的客户端会话；WMI 订阅 3 项为筛选器、消费者和绑定。

`Providers.cs` 通过系统 MI 客户端调用原提供程序，不加载 PowerShell。安全读取不触发扫描或处置；WMI 读取不创建、触发或删除订阅；磁盘和网络只查询。Defender 检测来源是产品保留历史，不是一次新的全机器威胁扫描。SMB 会话需要相应权限，原名称“SMB 客户端会话”的解释仍应明确为本机服务端上的连接。

存储原始数据的枚举值与旧显示值分别保留：总线、健康、运行状态、介质及 MBR/GPT 分区类型按系统签名的 Storage 类型定义转换，未知代码显示 Unknown，实际代码仍在 source_properties。单个运行状态保持字符串，多状态保持数组，空状态不猜为正常。

CIM 原始公共属性中的字节数组保持旧数值数组，普通字段中的字节值仍保持原 base64 描述；引用对象在普通字段保持身份字符串，在原始属性保留完整结构。敏感数组按整个字段保护，避免迁移改变数据表示或丢失订阅关系。

## 实机及正式包装器验证

正式结果：`target/native-registry-tests/1791973012664/summary.json`。隔离目录没有兼容脚本，Rust 包装器执行 14 个对应来源。13 个来源成功，1 个 SMB 会话来源在普通权限下被拒绝访问，与旧接口一致，没有提交空快照。

成功字段比对包括 1 个磁盘、4 个分区、1 个物理磁盘、Defender 状态/配置、安全产品登记和 Device Guard 各 1 项、2 个网络配置文件，以及 WMI 筛选器、消费者和绑定各 1 项。检测历史和 SMB 映射当前为空，原生与旧接口一致；不以空结果代替非空环境验收。

共享 CIM 转换改动后已回归任务与网络：`target/native-task-tests/1791973019813/summary.json` 验证 155 个任务及 2015 个稳定字段，`target/native-network-tests/1791973027533/summary.json` 验证地址、路由和可控 IPv4/IPv6 TCP/UDP 创建时间身份。动态值不以跨时间完全相等作为验收标准。

原生离线检查增至 20 项，涵盖原子快照、关闭来源、敏感数据、公开字节数组表示、未知存储状态及未加载 PowerShell 引擎。Rust 来源归属测试及全量来源清单已更新并通过。
