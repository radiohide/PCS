# 原生网络、任务与配置迁移验收

日期：2026-10-14。延续全量原生迁移目标，本批在第一批 19 项之后接入 22 项，当前源码路由为 81 原生 / 50 PowerShell 兼容 / 2 分组。原生路由表示由编译后端执行，不等于所有权限与环境都已返回成功数据。正在运行的增强后台尚未替换。

## 新接入范围

网络与任务 6 项：IP 地址、路由、TCP、UDP、计划任务、任务详情。注册表 15 项：浏览器策略、OneDrive 登记、输入配置、剪贴板配置、桌面配置、服务配置、登录初始化配置、IFEO/注入入口、环境配置、WinRM 配置、系统策略、时钟配置、待重启配置、用户软件登记、WSL 登记。另接入电源计划与电源配置。

地址与任务沿用基础单快照范围；其余项保留原 16 分片。身份、用户与机器范围、注册表 32/64 位视图、原限定路径与递归深度保持一致。注册表值按既有 evidence-v2 策略处理，多字符串及嵌套对象中的敏感内容也受保护，原值不展开环境变量。一个范围失败或超过预算不提交部分完整快照。

网络通过系统 MI 接口直接查询原提供程序，连接身份保留创建时间和所属进程。原系统 TCP 类型定义对新增 AppliedSetting 代码没有名称，原 getter 返回空；原生输出保留该解释字段的旧表示，同时在 source_properties 保留实际代码，避免丢失原始字段或制造迁移差异。

任务直接读取 MSFT_ScheduledTask，并固定调用只读 PS_ScheduledTask.GetInfoByObject；这里的 PS 是系统提供程序类名，不加载或启动 PowerShell。只读取配置和最近执行信息，不创建、运行或修改任务。未启用触发器的旧空结构表示继续保留，避免首次迁移产生假变化。每次运行的完整历史继续由事件记录补充。

- 正式网络包装器结果：`target/native-network-tests/1791971505926/summary.json`。12 个地址、40 条路由身份集合及字段一致；IPv4/IPv6 回环 TCP/UDP 固定测试对象的创建时间、进程、端口及全部稳定字段一致。全机器连接总数会变化，未以两次查询间总数相等证明连接正确。测试没有修改网络配置或网卡。
- 正式任务包装器结果：`target/native-task-tests/1791971508875/summary.json`。155 个任务身份一致，930 个基础稳定字段及 1085 个详情稳定字段比对通过。瞬时运行状态和最近执行时间等动态值不参与跨时间静态等值判断。
- 正式注册表包装器结果：`target/native-registry-tests/1791972071194/summary.json`。15 项中 11 项成功比对，包括 1112 个环境配置条目、65 个登录初始化配置条目、34 个策略条目和 10 个用户软件登记条目。浏览器/OneDrive/WSL 在本机限定范围内为空，空结果与原接口一致，不能替代这些产品安装环境的非空场景验收。
- 输入配置、服务配置、IFEO/注入入口和 WinRM 配置在普通权限下访问部分键失败；新旧查询均失败，原生没有提交空或部分快照。增强权限下的数据成功验收继续开放。
- 电源正式包装器结果：`target/native-registry-tests/1791972398267/summary.json`。当前终端服务远程会话中，系统提供程序在普通权限下拒绝读取，新旧结果一致；原生保持旧状态。没有切换电源计划，成功字段验收仍待增强权限。

`scripts/test-native-state.ps1` 最新结果：`target/native-state-tests/00a4128149364303b7ab9d28f5813de8/summary.json`。26 项核心状态来源在无任何兼容脚本的隔离目录运行，24 项成功，还原点及电源 2 项为明确的权限失败。原子范围、低完整性拒绝和原生 helper 缺失时无脚本回退检查通过。原生离线协议与保护检查增至 18 项。
