# 原生防火墙、IPsec 与 DNS 采集验收

日期：2026-10-14。本批接入 6 项原生路由：防火墙配置集、防火墙规则、IPsec 规则、DNS 配置、DNS 缓存和 hosts。当前累计迁移 61 项，源码为 101 原生 / 30 兼容 / 2 分组；完整目标尚未完成，运行中的增强后台尚未更新。

## 实现与范围

`NetworkConfiguration.cs` 直接调用系统 MI 提供程序及文件 API。防火墙规则读取 ActiveStore，并合并 Port、Address、Application、Service、Interface、InterfaceType、Security 七类过滤条件；不使用字段较少的规则接口替代原完整范围。关联缺失或超时拒绝提交部分完整快照。IPsec 同样读取 ActiveStore，未丢弃策略来源字段。

规则名称沿用 InstanceID，Profile 沿用 Profiles；状态文本包含原状态码。过滤器的空值表示 Any，单值数组保持标量、多值保持数组，原始属性独立保留。对应表示已用系统签名的类型定义与格式化函数、内存 CIM 对象核对，没有创建规则。

DNS 配置保留接口及地址族身份、服务器列表、原始属性和 Tcpip 注册表配置。DNS 缓存使用原始数字类型/状态/区段的字符串表示，不把显示名称写入身份。缓存是当前可读缓存，不是查询历史。hosts 保留原行号与多名称条目身份，排除注释，保持默认系统编码及 BOM 检测，拒绝重解析点或超过 1 MiB 的文件。

所有查询只读，不清理 DNS 缓存、不修改策略、不改写 hosts。生产路径不启动或加载 PowerShell。
