## 读取方式与边界

`PrintingShares.cs` 通过系统 MI 提供程序直接读取打印机、驱动和端口，调用固定只读 MSFT_PrintJob.GetByName 读取队列元数据。保留打印机/作业号/提交时间身份、状态、大小与页数，文档名称按既有敏感策略保护，不读取文档内容。没有发送、暂停或删除打印作业。

SMB 共享直接读取 MSFT_SmbShare，每个共享调用只读 GetAccessControlEntries，保留账户、允许/拒绝、访问权及原始属性。没有创建共享或修改 ACL。调用按来源有时间、条目和 ACL 数量预算，失败不提交部分完整快照，不以少字段的接口替代原采集范围。

WUA 沿用原生 IUpdateSession/IUpdateSearcher.QueryHistory，读取产品保留历史，不执行搜索、下载或安装。之前原型失败后，本次按普通应用完整性级别运行已成功；低完整性显式拒绝，避免把读取不到当作空历史。其他环境及正式部署成功仍待验证。
