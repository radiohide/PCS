# 原生快捷方式与登录启动项验收

日期：2026-10-14。本批接入登录启动项和桌面/开始菜单快捷方式 2 项。累计迁移 75 项，源码为 115 原生 / 16 兼容 / 2 分组。完整目标未完成，运行中的增强后台尚未更新。

`DesktopStartup.cs` 直接读取 HKLM/HKCU 的 32/64 位 Run、RunOnce、StartupApproved，以及当前用户/公共启动文件夹。保留原注册表数据和行身份、敏感命令保护、启动文件摘要及基础单快照范围。注册表和文件夹子项分别关闭时不执行对应查询；文件在摘要读取中变化拒绝提交不稳定结果。

快捷方式由编译宿主直接调用系统 WScript.Shell COM 元数据接口；这是 COM 对象，不启动 PowerShell、wscript/cscript 或脚本。不调用 Run、Exec、Save，也不执行快捷方式目标。保留四个原 Known Folder、限定递归范围、重解析点排除记录、参数保护、图标、快捷键和窗口样式。

已查明系统 computer.lnk 描述属性会返回 E_FAIL，旧接口表示为空；原生保留这一值，其他异常仍失败。系统描述采用原接口的线程语言，避免相同内容的语言变化被当作修改；仅改变采集线程，不改系统语言设置。

正式快捷方式结果：`target/native-registry-tests/1791976237066/summary.json`。88 条身份和全部字段一致。两项均由无兼容脚本的隔离目录中的正式 Rust 包装器完成；Rust 来源归属、源码库存及迁移清单通过。测试未改写注册表、快捷方式、启动配置或用户历史。
