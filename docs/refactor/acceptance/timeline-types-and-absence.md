# 时间线类型与易混淆场景

日期：2026-10-15。最新开发包固定为 `dist/dev`，界面版本 0.2.5。桌面 debug 程序同步更新，原数据目录配置保留。

## 0.2.5：明确发生时间也按 30 秒归组

真实登录日志在 16:09:04 的两条时间为 `08:09:04.0982607Z` 和 `08:09:04.0982704Z`，界面均显示同一秒。旧逻辑只为区间变化加入了 30 秒容差，单点时间仍比较原始字符串，造成两个相同时间标题。

现在明确发生时间、记录时间各自按时间值归组，组内最早到最晚不超过 30 秒；区间继续要求起止各偏差不超过 30 秒且共同重叠。不混合发生时间、记录时间和不确定区间。首屏和跨页使用相同规则，不按相邻记录连锁扩大。同一显示秒只显示一次时间，多秒则显示最早至最晚，跨日保留日期。两条记录和原始时间仍各自保存。

相关边界检查以及 28 个实际页面场景通过，包括该微秒样本、30 秒边界、跨页合并、原时间保留、展开详情、分类和折叠状态。仅更新界面与其版本，当前增强后台继续使用 0.2.4，无后台替换或额外提权。

时间线卡片及对象详情的最近变化均明确显示“类型：…”。名称不承担类型判断：同为 conhost.exe，可以是运行进程，也可以是监控文件；不根据扩展名猜测对象类型。详细标识仍默认折叠。

后续文案整改：下表用于说明语义边界，不作为界面逐条说教。界面已全面去除“不表示、不代表、不等于”等预设误解的解释，只陈述实际状态、范围和必要影响。例如进程说明为“此前的进程已不在运行列表中。”，内容摘要变化为“文件内容已变化。”，未签名为“文件未签名，发布者未验证。”。事件说明、采集目录及插件范围说明同步精简。104 条事件语义、101 种类型及页面交互回归通过。

| 场景 | 默认说明的含义 |
| --- | --- |
| 运行进程不再出现 | 进程已不在运行列表，不表示程序文件被删除 |
| 已加载模块不再出现 | 进程中已无此加载模块，不表示磁盘文件被删除 |
| 文件或文件夹不再列出 | 说明监控清单变化；仅有明确文件状态证据时才说明文件不存在 |
| 服务登记不再出现 | 区分登记变化、服务停止和程序文件删除 |
| 计划任务登记不再出现 | 区分任务登记变化和某次任务运行结束；运行结束也不自动表示成功 |
| 打印作业离开队列 | 可能完成或取消，不能仅由离队确认打印成功 |
| 网络连接、登录会话不再出现 | 不表示网卡、共享文件或账户被删除 |
| 软件、预配应用登记不再出现 | 区分安装登记、当前用户应用包与新用户预装配置 |
| 账户权限、用户配置登记不再出现 | 不表示账户或用户文件被删除 |
| DNS 缓存项不再出现 | 区分缓存刷新、过期和网络配置变化 |
| 证书、密钥登记不再出现 | 不推断私钥或密钥文件被删除 |
| 虚拟机、虚拟磁盘连接、容器不再出现 | 不推断虚拟磁盘文件、镜像或数据卷被删除 |
| 设备及设备驱动关联不再出现 | 不仅凭清单缺席判断卸载、断开或驱动文件删除 |
| 版本或摘要变化 | 版本信息变化不等于已检查文件内容；摘要变化不等于文件损坏 |

其他已知对象使用可读类型与对应的清单说明。类型或关联没有可靠依据时使用“系统事件/系统项目”，不套用进程退出或文件删除结论。前后字段不完整时不确认具体变化。

## 紧凑时间轴设计预览

2026-10-15：按用户选定的紧凑时间轴设计，去掉大号行为标题。下列为预览方案；产品已在 0.2.0 接入分组、滚动固定与文字适配，具体实现边界见末节。

- 信息顺序统一为：时间、对象名称、可读类型、变化值、必要影响、对象与记录详情入口。类型不靠文件名推断。
- 短状态和版本同行对比；长路径、命令、地址列表上下对比；名称与变化值允许换行，不裁掉当前状态。路径只在变化内容需要时默认展示。
- 多项变化显示数量摘要，具体字段在记录详情展开；首次记录、最近未发现、日志明确删除分别使用短标签。
- 读取失败显示读取状态，不画成“原值变成读取失败”；此前未记录时只显示本次值；隐藏信息不显示虚假的前后变化。
- 时间按日分组，区间只显示起止时间和“区间内变化”；跨天包含日期。任务结束和运行成功分别展示。
- 颜色表达已确认的运行状态、失败及需关注事项；一般配置或版本变化保持中性，不把所有变化当异常。

预览包含 12 类、101 种对象及 13 个边界/采集状态场景，均使用示例数据。101 类型与模型清单逐项核对，780px、320px 下共 215 个布局场景及详情交互通过；深浅外观已查看，无脚本错误。材料为 `target/timeline-gallery-qa.json`、`target/timeline-gallery-common.png`、`target/timeline-gallery-long-text.png`。

### 时间区间分组与滚动

按用户最新要求，同一时间区间只显示一个时间标签，右侧使用树形分支排列记录。当前区间采用下述 30 秒容差规则；精确时刻与区间记录分别分组。组内保留每条记录的对象类型、变化及详情入口。

桌面左侧时间标签在本组范围内固定，到达组尾后由下一区间接替。窄屏改为组顶横向标签，同样固定至本组结束。只使用一个列表滚动区域，不为每组增加独立滚动条。预览使用两组共六条示例，已实际验证同区间单标签、滚动固定、组间交接和窄屏固定；全部 101 类型布局检查仍通过。材料：`target/timeline-group-scroll-qa.json`、`target/timeline-groups-top.png`、`target/timeline-groups-pinned.png`、`target/timeline-groups-next.png`。

## 首屏读取与归组时机

时间线首次打开、切回页面或载入最新时，只请求前 200 条记录，取得后立即按 30 秒规则归组再显示。没有额外预读或遍历历史的启动流程。之后滚动到末尾再按每页 80 条串行追加，继续更新已有卡片。

分页边界可能截在一个时间组中间。仍可能有后续记录的卡片显示“已加载 X 条”；继续读取并越过该组的可合并时间范围后，恢复“X 条记录”。该标记只说明页面已加载的范围，不判断采集历史是否完整。

验证：22 项真实前端交互通过，首屏一次读取 200 条、滚动前将 80 条网络连接与 3 条域名解析缓存合成 83 条、没有额外预读、后续请求每页 80 条，分页边界标记可自动更新。本次独立只读查询实际后台的前 200 条耗时约 509 毫秒，由正式函数归为 6 张卡片，其中三张含多种类型；材料为 `target/first-200-live-merge.json`。页面截图为 `target/timeline-first-200-grouped.png`。

## 当前区间归组规则：起止时间各允许偏差 30 秒

按用户明确选择，区间记录只有同时满足以下条件才进入同一卡片：整组开始时间最大偏差不超过 30 秒，整组结束时间最大偏差不超过 30 秒，并且存在共同重叠区间。30 秒边界包含在内；首尾相接而没有重叠的区间保持分开。相邻两条接近不能使分组连锁扩张。

卡片显示最早开始到最晚结束，合计记录数及类型数；每条记录的原始时间不变，保留在详情。准确发生时间的事件、仅有记录时间的项目与区间记录分别归组。缺失或无效时间不合并。符合规则的跨午夜区间可以合并，卡片保留两端日期。

`timeline-time.js` 为首次渲染及跨页追加提供同一套规则。追加按原查询顺序逐条匹配，不直接吞并下一页已经分好的整组；分组边界和分类选择／折叠／详情状态在分页后保留。上述规则取代早期按完整时间戳严格相等的实现。

验证：21 项真实前端交互通过。独立检查覆盖 30 秒包含边界、超出 1 毫秒、开始或结束偏差过大、无重叠、时间缺失、时区表示差异、跨午夜及准确时刻隔离；跨页场景检查“0 秒／20 秒／40 秒”分为两组，且与一次读取的结果一致。使用此前只读取得的 600 条真实记录的时间及类型汇总，由正式归组函数验证：16 张变为 12 张，三张含多种类型；其中网络连接 80 条与域名解析缓存 3 条合为 83 条。材料为 `target/time-group-30s-production-evaluation.json`，未改写历史数据库。

## 时间组的分类开关与折叠

时间标签改为组内固定的控制卡片：显示完整时间区间、记录总数和展开／收起按钮。下方按具体对象类型显示“名称＋条数”快捷按钮，亮起表示显示，熄灭表示隐藏；每组独立控制，不改变页面顶部的全局筛选。

计数覆盖本组当前已读取的记录。分页合并同一区间时自动更新分类条数，保留已关闭的类型、整组折叠状态及打开的对象／日志详情。全部关闭时显示“本组类别均已隐藏”与“全部显示”，避免空白页面。0.2.2 起折叠摘要仍保留分类名称、数量和开关，再次展开恢复原来的分类选择。

分类只使用易读类型名称，不从对象名称或文件后缀推测。全部 101 种对象均能进入分类计数；名称相同的展示类型合并计数，原始记录身份不合并。类别较多时只在按钮区域滚动，保持时间和恢复按钮可见。窄窗口将控制区移到记录上方。

`timeline-groups.js` 仅控制现有记录节点，不读取数据库，不发起采集或对象查询；隐藏不移除节点。分页追加仅更新涉及的时间组。原查询队列和自动分页规则保留。

验证：19 项真实前端交互场景通过，包含 79 条记录的 50／18／8／3 分类、开关与全部恢复、键盘折叠展开、960／700 像素窗口、101 类型按钮可达性、跨页计数与折叠／筛选状态保留、其他时间组不受影响和固定时间标签滚动。深浅两种主题截图保存在 `target/timeline-group-controls-*.png`。

## 0.2.3 全部折叠／展开模式

时间线顶部、立即采集旁增加“全部折叠／全部展开”切换按钮。点击统一设置当前所有时间组，分类选择与已展开的记录／对象详情保留；单个组仍可独立展开或收起。新增时间组按全局模式显示，已有组的手动状态不因分页改变。全局模式保存在本机界面偏好中，筛选、载入最新、切换页面或重新打开后沿用，不重写采集数据。

切换仅操作现有节点，不触发采集或查询。为避免折叠后列表变短使分页入口自动进入视口、继而连续读取历史，时间线在切换模式或以折叠模式刷新后等待继续滚动意图；鼠标滚轮、触摸、向下翻页键与滚动条操作均可继续分页。折叠模式一次继续滚动读取一页，仍使用串行队列和 80 条后续页；首屏一次 200 条不变。其他页面沿用原分页行为。

## 0.2.2 分类配色与同行摘要

按用户选定的“同行摘要”实现：折叠卡片以时间、分类按钮、总数与展开入口依次排列；较窄窗口将分类放到第二行。分类较多时按钮区域仍有界滚动。时间与数量区域均可展开／收起，分类按钮不触发整组展开。

类别使用固定颜色，按钮与记录的类型标记一致。常见类别分别使用蓝、青、绿、琥珀、靛及粉色；其余类别从同一套十色主题配色按名称稳定分配，相同的可读类型名称始终同色。颜色可以复用，名称和条数始终保留，不以颜色单独区分类别或表达异常。关闭类别后变灰，当前显示数和“全部显示”在折叠时仍可使用。
