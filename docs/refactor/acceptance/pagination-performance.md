# 分页性能实测与批次调整（0.2.10）

日期：2026-10-16。使用当前运行中的增强后台 0.2.6、实际历史库与实际 WebView2 窗口；采集保持运行，没有删除历史、清缓存或改变权限。起始库大小 14.64 GiB，状态统计为 14,003 个对象、190,182 条原始记录、161,383 个状态采集批次。

## 后台读取

使用真实命名管道串行读取，分别测首屏和同一游标序列的下一页；每种大小轮换顺序采样三次。耗时包含 IPC 接收与 JSON 解析。测试上限为现有契约的 200 条，没有修改后台上限。

| 查询 | 每页 | 首屏中位耗时 | 下一页中位耗时 | 下一页平均响应 |
|---|---:|---:|---:|---:|
| 时间线 | 80 | 701 ms | 756 ms | 194 KiB |
| 时间线 | 120 | 905 ms | 1049 ms | 284 KiB |
| 时间线 | 200 | 1183 ms | 1149 ms | 462 KiB |
| 系统对象 | 50 | 1359 ms | 2489 ms | 776 KiB |
| 系统对象 | 100 | 1501 ms | 2407 ms | 2152 KiB |
| 系统对象 | 200 | 1854 ms | 2933 ms | 4793 KiB |

对象 50 条组有一次达到后台六秒预算而超时，该组中位数仅有两次成功样本，不能视为三个样本均成功。100 条首屏也出现过 5.41 秒的慢样本。当前负载存在波动，以上是本机当前数据的短时样本，不是长期延迟保证。

## 实际窗口与绘制

直接在 WebView2 内通过真实 IPC 将 1000 条时间线记录读入同一套正式渲染器：首屏 200、后续 80 时共 11 次查询，耗时 10.89 秒；每次 200 时共 5 次，耗时 6.76 秒。这一阶段未包含自动分页调度，单独用于比较读取和插入成本。

再用同一份 1000 条真实数据排除查询波动，对比单次绘制大小：

| 每次绘制 | 最长单段耗时 | 全部绘制 CPU 耗时 |
|---|---:|---:|
| 200 条 | 134 ms | 547 ms |
| 100 条 | 59 ms | 516 ms |
| 50 条 | 35 ms | 522 ms |

因此增大读取批次，并在每 50 条之间让出一帧。减少查询往返时，不把 200 条一次性压到界面主线程。分段过程中更改筛选、刷新或离开页面会取消旧的未完成绘制；原始响应仍由模型渲染层解释。

最后关闭并行回归测试，通过实际主滚动容器和正式自动分页控制器串行复测：旧版 80 条后续页读入 1000 条共 11 次查询，完整链路 **14.58 秒**；候选 200 条后续页、50 条分段绘制共 5 次查询，**9.99 秒**，本轮减少 **31.4%**。这组包含串行队列、预加载触发和分段绘制，不能与前一阶段的直接插入时间混用。加载期间的帧间隔第 95 百分位均约 16.8 ms，最长从 83.3 降至 50.1 ms；仍有两帧超过 50 ms，不能声称完全无卡顿。候选代码只装入独立验收窗口，不改后台。

模块文件历史的实窗样本：50/100/200 条分别约 197/392/863 KiB；100 条绘制约 28 ms，200 条约 70 ms。该项只取了一轮，不能据此声称 100 条查询始终比 50 条快。

## 最终调整

- 时间线：首屏和后续均读取 200 条，界面分成 50 条绘制；沿用提前一屏读取、按游标追加和成组规则。
- 系统对象列表、对象树分支和搜索：50 提高到 100 条。避免直接将重响应放大到 200 条。
- 模块文件与资源历史：50 提高到 100 条。
- 状态对比历史原来已读 200 条，保持；对象候选仍保留按需搜索。
- 全窗口自动读取串行；关闭分支、折叠和隐藏类别的限制、错误停止及游标保护保留。不提高采集频率。

## 仍需处理的对象查询开销

在实测 200 个对象的首屏中，来源信息约占响应数据九成。`coverage_of` 当前按来源关联多个采集范围，导致同源的范围资料重复出现在每个对象里。后续需要按实际采集证据范围精确关联并减少重复传输；对象身份范围与采集范围不同，不能简单加一个 scope 相等条件来删减材料。

本次先调整有实测依据的读取和绘制批次，没有改写采集归属、删除来源资料，或宣称对象查询的六秒超时已根治。汇总数据保存在同目录的 `pagination-performance.json`；原始响应及临时 WebView 缓存仅在忽略目录，未进入 Git。

0.2.10 已构建并更新到固定 `dist/dev` 与 desktop debug 目录，普通运行窗口已恢复且保持响应。后台 PID 55204、运行文件散列及原启动配置未改变；验收临时本机调试端口已关闭。33 项页面交互、15 项对象树、自动分页、查询队列、渲染契约、查询消费、刷新及代码归属检查通过。
