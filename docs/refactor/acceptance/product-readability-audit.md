另有同账户管理员只读验收的 732 个驱动包材料与接口缓存，详见原生权限验收记录，不再作为新的独立数据库计入。

## 按系统影响评估当前状态

| 功能 | 当前状态 | 对用户的影响与剩余工作 |
|---|---|---|
| 系统变化记录与查询 | 已通过基础和真实数据验收 | 可查看已记录的变化；未记录或已覆盖的历史不能补回 |
| 模块文件跟踪 | 主链路已通过可控宿主验收 | 能提示曾加载文件的缺失、结构异常和变化；首次就无法加载的模块可能发现不了 |
| 真实 SIHost | 当前会话的只读观察未发现目标，尚无正向验收 | 不能据此判断桌面功能正常、SIHost 崩溃或第三方功能失效 |
| 日志与权限覆盖 | 受权限、记录设置和组件安装情况影响 | 部分系统变化可能漏记；管理员权限也不能补回从未记录的历史 |
| 个别密钥提供程序信息 | 仍有 3 个范围/环境错误待处理 | 相关密钥元数据判断不完整；不能把三项全部当成权限不足 |
| 原生采集与兼容脚本 | 当前归属为 40 项原生、91 项兼容待迁移 | 模块和自动文件跟踪由原生后端完成；其他部分的默认脚本启动仍需完善，不能宣称已全部原生化 |
| 故障定位与长期稳定性 | 尚未完成 | 暂不能自动确认异常原因；真实 SIHost、Windows 11、24 小时运行、跨目录移动和中断期间补读仍待验证 |

短时测试中，50 次无关文件写入没有增加模块文件检查；后端在 15 秒空闲观察中的整机 CPU 占比约 0.29%。这些局部结果支持当前防重复采集设计，但不能代替长期、所有子进程和大规模监控的资源评估。

## 文案标准与已修正内容

默认界面先说当前状态，再说可能影响。短句表达；不知道就写“暂不能确认”。来源标识、账户编号、签名返回码、规则版本及完整原始记录放在可展开的详情中。

| 场景 | 当前默认表达 |
|---|---|
| 文件缺失 | 文件已缺失，下次启动或使用相关功能可能失败。 |
| 文件结构异常 | 文件结构异常，下次加载相关功能可能失败。 |
| 文件变化 | 文件已变化，尚未确认相关功能是否受影响。 |
| 文件未签名 | 文件未签名，暂不能确认发布者；这不表示文件损坏。 |
| 文件暂不可读 | 本次无法检查，暂不能确认文件状态。 |
| 进程未发现 | 本次未发现进程，暂不能判断是否影响桌面功能。 |
| 采集信息不全 | 信息不全，相关异常可能漏报。 |
| 记录处理失败 | 部分记录未能显示，变化可能遗漏。 |
| 检查未完成或没有检查项 | 尚未确认；不显示“0 项异常”来暗示正常。 |

已检查总览、时间线、系统对象、SIHost、状态对比、采集插件、采集健康和系统配置八个入口。减少默认统计项和说明文字；统一状态与影响；保留历史不足及敏感信息显示提示。没有改变采集周期、权限授权、系统记录设置、保留策略或数据协议。

页面验收发现并修复：采集插件存在执行结果时调用未定义的 `pretty`，导致整个页面无法打开。现直接安全展示完整结果，不依赖该函数。
