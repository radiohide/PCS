# 敏感字段与完整原始证据

2026-09-11：按用户后续要求替换原“丢弃/不可逆脱敏”策略。此文优先于前一版采集审计中的隐私策略说明。

- 密码、令牌、私钥等**现有采集范围内来源已经提供的字段**，加密保存原值，默认显示 `******`，不隐藏字段。
- 设置 → 敏感信息显示 → **显示敏感信息明文**。默认关闭，保存后持久化在本机数据库。关闭后后台不向界面发送明文或密文；打开后由后台解密。时间线、系统对象、详情及原始数据使用同一控制。
- Windows 当前用户 DPAPI 加密，不保存明文密钥。同一 Windows 账户仍可解密；这不是对已控制该账户的程序提供隔离。不要随意分享数据库，换账户/损坏用户密钥时可能无法解密。
- 事件完整源 XML 加密保存，包含未映射的 XML 结构。长字段保留完整加密值，预览上限不会丢失尾部；格式化正文不再截断。
- 序列化超限/加密失败/读取失败会报缺口；不推进未成功保存事件的断点。单条仍受协议硬上限影响，不承诺无限大的原子消息可保存，也不把失败当成功。
- DPAPI 每次生成不同密文，入库对比使用解密后的值判断是否变化，不因密文随机化产生虚假变更。
- 旧版仅有摘要/已经丢弃的原值无法恢复，字段仍显示 `******` 并注明原因，等待来源重新采集。
- 不因为显示开关而扩大目录范围、扫描密码库、打开私钥文件，或启用系统审计。来源从未记录、已被系统覆盖和无权限的数据无法补回。

历史容量策略默认改为“无限增长”，不自动清理旧历史；同时需要监控磁盘容量。若用户以后显式选择“限额滚动”，旧历史仍会按该策略删除。磁盘满时必须报错，不能承诺无限存储。
